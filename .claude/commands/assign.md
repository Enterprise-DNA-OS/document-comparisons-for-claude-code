# /assign

Change --owner or --due-on for --ref=<comparison>. This invalidates the previous signoff.

Use the one CLI: `npm run comparisons -- assign`. Options use `--name=value`; add the options named above. Every write needs --actor with the actual operator. Confirm the record and facts before writing.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
