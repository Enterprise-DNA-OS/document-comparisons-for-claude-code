# /export

Write a new file with --file=<path>. JSON includes every collection and history. --kind=<collection> writes CSV with spreadsheet formula protection. It refuses to overwrite an existing file.

Use the one CLI: `npm run comparisons -- export`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
