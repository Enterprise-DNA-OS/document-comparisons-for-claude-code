# /review-queue

Read each comparison, owner, deadline and outstanding decision count.

Use the one CLI: `npm run comparisons -- review-queue`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
