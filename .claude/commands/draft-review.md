# /draft-review

Write the weekly review into drafts from the current queue, attention and owner load.

Use the one CLI: `npm run comparisons -- draft-review`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
