# /add-version

Add an immutable source with --ref=<document> --label=<version> --file=<txt-or-docx>. Read the extraction warning. Store the original file in the authorised document store.

Use the one CLI: `npm run comparisons -- add-version`. Options use `--name=value`; add the options named above. Every write needs --actor with the actual operator. Confirm the record and facts before writing.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
