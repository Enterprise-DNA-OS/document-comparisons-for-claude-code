# /attention

Find overdue comparisons, unchecked scope, stale reviews and unresolved high-priority changes.

Use the one CLI: `npm run comparisons -- attention`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
