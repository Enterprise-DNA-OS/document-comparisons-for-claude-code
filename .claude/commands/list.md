# /list

Read a collection with --kind=documents|versions|comparisons|changes|decisions|signoffs|activity|import_batches.

Use the one CLI: `npm run comparisons -- list --kind=documents`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
