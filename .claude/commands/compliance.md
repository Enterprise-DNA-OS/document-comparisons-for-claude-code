# /compliance

Read record checks for retention, confidentiality and comparison scope. These are evidence prompts, not legal certification.

Use the one CLI: `npm run comparisons -- compliance`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
