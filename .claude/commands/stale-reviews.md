# /stale-reviews

Read comparisons without a review update for fourteen days.

Use the one CLI: `npm run comparisons -- stale-reviews`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
