# /signoff-history

Show which signoffs refer to the current revision and which are stale.

Use the one CLI: `npm run comparisons -- signoff-history`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
