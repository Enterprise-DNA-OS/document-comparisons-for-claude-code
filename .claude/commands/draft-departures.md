# /draft-departures

Read --ref=<comparison> and its history, then write the departures working paper into drafts. A person reviews it before sharing.

Use the one CLI: `npm run comparisons -- draft-departures --ref=CMP-101`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
