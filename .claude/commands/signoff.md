# /signoff

Read show, changes and compliance first. Use --ref=<comparison> --evidence=<reference> only on the named independent reviewer's instruction. Open or held changes, unchecked scope and due privacy reviews block signoff. This never authorises sending or executing the source agreement.

Use the one CLI: `npm run comparisons -- signoff`. Options use `--name=value`; add the options named above. Every write needs --actor with the actual operator. Confirm the record and facts before writing.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
