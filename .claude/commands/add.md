# /add

Add a document with --code, --title, --matter, --owner and --retention-on=YYYY-MM-DD. Classification defaults to confidential.

Use the one CLI: `npm run comparisons -- add`. Options use `--name=value`; add the options named above. Every write needs --actor with the actual operator. Confirm the record and facts before writing.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
