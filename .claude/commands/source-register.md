# /source-register

Read source filenames, version labels, extraction scope and file hashes.

Use the one CLI: `npm run comparisons -- source-register`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
