# /open-changes

Read the changes still awaiting a decision, across all comparisons.

Use the one CLI: `npm run comparisons -- open-changes`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
