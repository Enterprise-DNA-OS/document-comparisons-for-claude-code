# /changes

Read the full change text and current decisions for --ref=<comparison>.

Use the one CLI: `npm run comparisons -- changes --ref=CMP-101`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
