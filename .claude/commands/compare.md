# /compare

Compare two versions of one document: --ref=<document> --code=<comparison> --original=<label> --revised=<label> --owner=<person> --due-on=YYYY-MM-DD. This compares text, not page layout.

Use the one CLI: `npm run comparisons -- compare`. Options use `--name=value`; add the options named above. Every write needs --actor with the actual operator. Confirm the record and facts before writing.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
