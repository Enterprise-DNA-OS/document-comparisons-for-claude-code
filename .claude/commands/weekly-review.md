# /weekly-review

Build the Monday review from review-queue, attention and reviewer-load. Name the owners and the unresolved decisions. Do not invent recommendations about legal effect.

Use the one CLI: `npm run comparisons -- weekly-review`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
