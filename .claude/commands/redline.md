# /redline

Create a read-only text redline for --ref=<comparison>. Imported reports need draft-departures instead. Review both original documents before relying on this text-only output.

Use the one CLI: `npm run comparisons -- redline --ref=CMP-101`. Options use `--name=value`; add the options named above. Add --json for complete values when human output truncates text.

Present the result with its source record. Never send, delete or share records. Never turn a missing fact into a pass.
